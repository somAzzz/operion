## 已修复

### I02：对象与字段绑定

`business_facts.py` 从成功工具结果生成对象、别名、字段、值、币种和证据指针。校验显式数量、金额、状态时先定位对象，再比较对应字段。多对象指代不明、同对象存在冲突证据、币种未知或不符均不放行；订单总额不能借用单价，默认业务状态不能借用来源状态。能力查询不再关闭整个回答的对象 ID 检查。

三个原始反例（币种错误、客户数量互换、订单金额/状态互换）与正确对照已经成为固定回归。另覆盖相同上下文中单价与总额混淆、多个对象省略归属、冲突证据和缺币种。测试使用手写输入和布尔预期，不使用生产 helper 生成 gold。E2 增加绑定检查；多次匹配工具的最终答案不再只与最后一次调用的数值集合对比。

校验政策版本为 `business-facts-v2`。未识别到受保护声明的回答记录 `NO_PROTECTED_CLAIMS`，不能解释为整段自然语言已证实。当前仍是受限语法的确定性校验：未完整覆盖代词、跨句指代、任意表格、税额、单位换算和所有业务字段。歧义输入可能保守拒绝，真实模型误拒绝率需要重新测量。运行时与 E2 仍复用部分解析逻辑；独立手写反例是回归保障，不等于独立通用语义评分器已经完成。

### 取消输出与延迟观察

取消回调不再将未验证的模型消息存入会话历史，保留之前已经提交的历史。回归测试注入部分文本并触发取消，验证文本既不出现在 SSE，也不进入历史。新增 `operion.run.first_verified_text_ms`，与已有首个 SSE 事件延迟分开；该值是服务器释放已验证文本的时刻，不是浏览器绘制时刻。

### I16：测试数据库生命周期

`verify.sh offline` 主动移除测试 DSN。`test_postgres.py` 不再接受用户提供的目标连接，自动新建一个 `postgres:16` 容器，使用随机密码、随机 loopback 端口、唯一名称和所有权标签，无业务数据挂载。容器就绪后才发放进程内测试能力；直接设置 DSN 调用破坏性测试会在连接前拒绝。结束时校验标签并删除本轮容器。

数据库测试需要可用的 Docker daemon；Docker 不可用会失败，不会回退到已有数据库。异常由 finally 清理；操作系统强制杀死进程或 Docker daemon 故障仍可能留下测试容器，应按 `operion.test-owner` 标签检查，不能批量删除其他容器。CI 改为使用相同 runner。

## I15：已可用的统一案例入口

```bash
scripts/verify.sh offline
scripts/verify.sh postgres
scripts/verify.sh case
scripts/verify.sh case fact-binding --layer domain
scripts/verify.sh case wrong-answer --layer agent
scripts/verify.sh case mcp --layer mcp
scripts/verify.sh web
```

案例目录：[evaluations/developer/cases.json](../../evaluations/developer/cases.json)。目前包含正常读取、越权、来源故障、错误答案、取消、事实绑定、真实 MCP 和数据库保护，合计 9 个 case/layer 组合。`agent` 层使用 FunctionModel 和本地 API/SSE 测试；`mcp` 层启动真实子进程并验证 initialize、tools/list、tools/call、越权及非法参数。尚不提供 `live` 或浏览器层，未支持的选择会报错，不静默跳过。

每次运行创建独立 `reports/developer/<run-id>/`：

- `manifest.json`：commit、跟踪差异 hash、源码/测试/fixture/case hash、依赖锁 hash、Python、模型和数据模式、运行状态。
- 每个组合的 JSON 和日志：测试数量、失败/错误/跳过、断言 expected/actual 差异（失败日志）、案例业务预期及重跑命令。
- `junit.xml` 和 `index.html`：用于 CI 与本地查看；HTML 对案例文本转义。

执行过程中逐案例原子更新 manifest，保留 RUNNING 和部分日志；单案例超时/无结果标 BLOCKED，跳过标 SKIP，只有所有必选组合 PASS 才返回 0。CI 上传该目录。强制失败、必选跳过及空案例选择均有 runner 自测，确认不能返回成功。报告使用公开 fixture，不采集真实 ERP、凭据或真实 LLM 内容。

该入口是 I15 的最小实现，尚未统一所有工具参数/返回值、协议 request ID、trace/span 事件和真实模型输入输出，也尚未提供完整时间线、自动语义 diff 或浏览器 trace。不要把断言报告称为已完成的全链路内容重放。
